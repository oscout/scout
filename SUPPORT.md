# Support

## Installation or usage

Start with the [quickstart](./docs/quickstart.md), then run:

```bash
scout doctor
scout whoami
```

Open a GitHub issue when you can provide a reproducible Scout-core bug or a
focused public feature request. Include the Scout version, platform, relevant
command, expected result, and sanitized output.

## Product and hosted-service questions

The OpenScout native applications and hosted services are maintained outside
this public core repository. Use [oscout.net](https://oscout.net) for product
context and contact routes.

## Security

Do not post vulnerabilities publicly. Follow [SECURITY.md](./SECURITY.md).
